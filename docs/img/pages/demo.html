BinSpec 编辑器

左写规则、右看结构、下看字节。三者共用一个游标：点结构树跳 hex，点 hex 反查节点。

png.bspec 编译通过 1 条 lint 建议 
#pragma endian = "big"
// PNG 文件头：8 字节魔数后紧跟一串 chunk

struct PNG {
    u8  magic[8] #[assert: $ == "\\x89PNG\\r\\n\\x1A\\n"];
    Chunk chunks[until(u32 $ == 0x49454E44)];   // IEND
};

struct Chunk {
    u32 length;
    char type[4];
    u8  data[length] #[comment: "载荷", optional];
    u32 crc #[assert: $ == std::checksum::crc32(data)];
};

fn main() { PNG file at 0x0; }

AI 猜结构

模型只是零件，verifier 才是产品。生成 → 编译 → 执行 → 10 条不变量校验，不合格就带错误重写，最多 3 轮。

本地模型 · 7B 量化 采样 48 KiB / 64 KiB verifier 通过 8/10
正在按采样结果校验
本机只发了 48 KiB 采样（头 4 KiB + 尾 4 KiB + 熵谷 16×512 B + 对数间隔 16×256 B），未上传文件本体。
回合动作结果耗时
1生成 PNG 结构（含 chunk 循环）I3 跨采样不一致1.8 s
2只看出错段 + 前后 32 B 重写I5 长度字段不自洽0.9 s
3补 crc 断言、修 until 条件I1~I10 通过 8 项0.8 s
