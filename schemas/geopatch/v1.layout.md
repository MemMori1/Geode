# `.geopatch` v1 字节布局

> 权威定义见 `docs/23-file-formats.md` §3.6；本文件只把字节顺序抄成可对照的表，
> 任何冲突以 §3.6 为准。**大端**，无 BOM，允许尾部 1..=4 个 `0x00` 填充（读侧忽略）。

## 头（32 B，定长）

| 偏移 | 长度 | 字段 | 类型 | 约束 |
|---:|---:|---|---|---|
| 0 | 8 | `magic` | bytes | `47 45 4F 50 41 54 43 48`（`GEOPATCH`），否则 EB002 |
| 8 | 2 | `fmt_ver` | u16 | `== 1`；`> 1` ⇒ EB001（不写盘，可只读列记录摘要） |
| 10 | 2 | `flags` | u16 | bit0 `HAS_FILE_META`（置位则首条必须是 `0x10`）；bit1..15 必须 0，否则 EB005 |
| 12 | 4 | `header_crc32` | u32 | CRC-32/IEEE，覆盖字节 `0..12` |
| 16 | 8 | `base_size` | u64 | 应用前目标字节数，用于预检 |
| 24 | 4 | `record_count` | u32 | 必须等于可解析记录数，否则 EB014 |
| 28 | 4 | `reserved` | 4×u8 | 写 0，读忽略 |

## 记录帧

```
kind u8 │ seq u64 │ payload_len u32 │ payload[payload_len] │ crc32 u32
 0        1          9                 13                   13+len
```

- `crc32` 覆盖 `0..13+payload_len`（含 `kind`/`seq`/`len`/`payload`，不含自身）⇒ 不符 EB011。
- `seq` 从 1 起严格 +1；乱序/重复/跳号 ⇒ EB012。
- `payload_len ≤ formats.geopatch.max_record_bytes`（默认 64 MiB）；`13+payload_len+4 >` 剩余 ⇒ EB013。
- 未知 `kind` ⇒ EB006 **跳过该帧继续**（`payload_len` 自描述）。

## 载荷

| kind | 名称 | 载荷 |
|---:|---|---|
| `0x01` | Overwrite | `at u64 │ len u64 │ data[len]`（`len` 必须等于被替换长度） |
| `0x02` | Insert | `at u64 │ len u64 │ data[len]` |
| `0x03` | Remove | `at u64 │ len u64`（无 data） |
| `0x04` | Checkpoint | `label_len u16 │ label[label_len]` |
| `0x12` | Comment | `text_len u16 │ text[text_len]`（UTF-8，≤4 KiB） |
| `0x10` | FileMeta | `head_len u32 │ base_head_blake3[32] │ path_len u16 │ path[path_len]` |
| `0x11` | FinalLen | `final_size u64`；**必须是最后一条** |

> 文档 §3.6 的最小示例里把 `payload_len` 写成 `09`，那是排版占位：Overwrite 的载荷
> 恒为 `16 + len`（1 字节数据时为 `0x11`）。真实取值以 `tests/vectors/geopatch/v1/` 为准。

## 应用规则

1. 先只扫不应用：头 CRC、全部记录 CRC、`seq`、`record_count`、`FinalLen` 位置；
2. 全过才按序应用（**全量预扫，不边读边改**）；
3. 应用期任何失败 ⇒ 回滚到应用前 checkpoint（整体是一个可撤销事务）；
4. 应用后 `len() == final_size`，否则 EB014。
