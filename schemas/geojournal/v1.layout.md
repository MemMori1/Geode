# `.geojournal` v1 字节布局

> 权威定义见 `docs/23-file-formats.md` §3.8（头 80 B；17 §4.6 标称 64 B 系笔误）。
> **大端**。只记 `EditOp`，绝不记文件副本。

## 头（80 B，定长）

| 偏移 | 长度 | 字段 | 类型 | 约束 |
|---:|---:|---|---|---|
| 0 | 8 | `magic` | bytes | `47 45 4F 4A 52 4E 30 31`（`GEOJRN01`），否则 EB002 |
| 8 | 2 | `fmt_ver` | u16 | `== 1`，否则关卡 1 失败 ⇒ EB001 |
| 10 | 2 | `flags` | u16 | 保留写 0 |
| 12 | 16 | `doc_uuid` | ULID 16 B | 必须等于 `docs[].doc_uuid` 的二进制形式 |
| 28 | 1 | `base_kind` | u8 | `0x00` file / `0x01` untitled / `0x02` provider |
| 29 | 8 | `base_size` | u64 | base 字节数 |
| 37 | 4 | `head_len` | u32 | 头部采样长度 |
| 41 | 32 | `base_head_blake3` | bytes | 关卡 4 的唯一依据 |
| 73 | 7 | `reserved` | 7×u8 | 写 0，读忽略 |

**头无 CRC 是刻意的**：头只写一次，损坏由 magic/`fmt_ver`（关卡 1）与 base 指纹（关卡 4）检出；
加 CRC 会把"头一字节翻转"从"可识别"退化为"整份只剩 Error"。

## 记录帧

与 `.geopatch` 完全相同：`kind u8 │ seq u64 │ payload_len u32 │ payload │ crc32 u32`，
CRC 覆盖 `0..13+payload_len`。

| kind | 名称 | 载荷 | 语义 |
|---:|---|---|---|
| `0x01` `0x02` `0x03` | Overwrite / Insert / Remove | 同 `.geopatch` | 等长替换 / 插入 / 删除 |
| `0x04` | Checkpoint | `label_len u16 │ label[label_len]` | 撤销分组边界 |
| `0x05` | SaveMark | `new_base_size u64 │ new_head_blake3[32]` | 保存成功后截断重写并更新头 |
| `0x06` | FinalLen | `len u64` | 回放后 `len()` 必须等于末条 |

## 四道关卡

1. magic + `fmt_ver` ⇒ EB002 / EB001；
2. 逐帧 CRC ⇒ 不符 EB011：**停止回放、标 `Partial`**，已回放前缀仍用于恢复；
3. `seq` 严格 +1 ⇒ EB012，按首个异常前截断；
4. base 指纹（`base_size` + `base_head_blake3`）⇒ 不符走强制恢复；末条 `FinalLen` 必须匹配。
