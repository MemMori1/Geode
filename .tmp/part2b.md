### 4.3 全局文档状态机
```
             open()                 首屏有字节
  [Empty] ----------> [Loading] ----------------> [Ready] <-----------+
    ^                    |   |                     |   ^              |
    | close()            |   | 权限/被占用/长度未知  |   | 保存成功      |
    |                    |   v                     |   |              |
    |              [ReadOnly] <---------------------+   |              |
    |                    |  以读写重开 / 另存为        |              |
    |  一个字节都读不到    v                            |              |
    +--------------- [Failed]                          |              |
  [Ready] --外部改动--> [Conflict] --Reload/KeepMine/SaveAs--> [Ready] |
  [Ready] --子功能失败--> [Degraded] --子功能恢复/重试--> [Ready] ------+
  [Recovering] --恢复成功(标 dirty)--> [Ready]；--丢弃--> [Empty]
```

| 状态 | 可用命令 | 禁用命令 | 状态栏文案 | 恢复路径 |
| --- | --- | --- | --- | --- |
| Empty | open / new / 最近 / 内容库 / help | 全部 Edit、Search、Nav、Save | `没有打开的文档` | 打开、拖放、从模板新建 |
| Loading | close、取消、view.* | Edit、Search、Structure、Save | `正在打开 report.bin…（20.0 GB）` | 完成→Ready；权限→ReadOnly；读不到→Failed；Esc→Empty |
| Ready | 全部（按 `Caps` 裁剪） | 无（无改动时 Save 置灰） | `0x00001A3C \| 选区 256 B \| 20.0 GB \| 补丁 12` | 冲突→Conflict；权限丢→ReadOnly；子功能挂→Degraded |
| ReadOnly | 只读全集 + save_as + reopen_readwrite | 全部 Edit 原语、Save、粘贴 | `只读 · 无法写入（E6001 权限不足）` | 修权限后「以读写重开」；另存为 |
| Conflict | 只读全集 + reload / keep_mine / save_as | Save（直到决策完成） | `文件已被外部修改（21:47）` | Reload→Ready；Keep mine→Ready（强制 .bak）；SaveAs→新文档 |
| Recovering | 恢复对话框、只读浏览 | Save、自动保存、Edit | `恢复中：3 个文档待确认` | 恢复→Ready（dirty）；丢弃→Empty；失败→Failed |
| Degraded | Ready 全集减去失败子功能命令 | 仅失败子功能的命令 | `部分功能不可用：diff 已降级（块级精度）` | 子功能恢复即回 Ready，或手动重试 |
| Failed | close、retry、导出诊断、help | 其余全部 | `无法打开 report.bin（E6005 格式校验失败）` | Retry→Loading；导出诊断；关闭→Empty |

**只读降级优先于拒绝打开**（`00 §9`、`06 §6`）：① 权限不足、文件被锁、设备忙、长度未知、目标只可读，一律进 `ReadOnly`，不进 `Failed`；② `ReadOnly` 必须给出「另存为副本」，数据仍可加工；③ 只有「一个字节都读不到且无缓存」才进 `Failed`，且保留 `file.retry`。把可读文件显示成错误，算缺陷。

### 4.4 文案规范
**语气**：直陈句、动词开头、一句一件事；不道歉（不写「抱歉」「对不起」）、不用感叹号、不写「出错了」「错误！」「请稍候」这类空话，不用「我们」；数字必带单位（`3.2s`、`1.2 GB`、`0x1A3C`）；陈述事实不归咎（写「文件已被其它程序修改」，不写「你改错了」）。

**术语表**（唯一对应，右列说法一律禁止出现在 UI）：

| 概念 | 中文统一用 | 标识符 | 不要混用为 |
| --- | --- | --- | --- |
| 字节位置 | 偏移 | `offset` / `Offset` | 地址（仅磁盘与进程地址空间）、位置、pos |
| 插入点 | 游标 | `cursor` | 指针、caret；（05/16 正文的「光标」为同义旧词，UI 一律用「游标」） |
| 选中区间 | 选区 | `selection` | 选择、高亮（高亮是渲染效果，不是数据） |
| 一处编辑记录 | 补丁 | `patch` / `PatchSet` | 修改记录、变更、diff |
| 有未保存补丁 | 已修改 | `modified` / `dirty` | 脏、未保存（作状态名时） |
| BinSpec 解析节点 / 节点内的命名值 | 结构 / 字段 | `Node` / `field` | 结构体、类型、属性、成员 |
| 比对结果 | 差异 | `diff` / `Hunk` | 补丁（严禁混用，`09 §4.7`） |
| 显示前变换图 | 处理器图 | `graph` / `Node` | 管线、流程图 |

**错误话术三段式**：第一句**发生了什么**（对象 + 动作 + 结果，陈述句）；第二句**为什么**（机制，不带内部行话）；第三句**你能做什么**（动词开头 + 具体对象 + 至少一个出口）。三段分行呈现（线框 7），不合并成段。

| # | 坏例 | 好例 |
| --- | --- | --- |
| 1 | 出错了 | 无法写入 `/dev/sda`：设备被系统占用。该设备正被另一个程序独占打开，写入会破坏它正在使用的数据。请以只读方式打开，或关闭占用该设备的程序后重试。 |
| 2 | 文件打开失败 | 无法打开 `report.bin`：权限不足（EACCES）。该文件只允许所有者读取。请授予读取权限，或以管理员权限重新打开。 |
| 3 | 无效的搜索模式！ | 无法搜索 `?? ??`：模式里没有固定字节，会匹配全部位置。请至少写一个确定字节，例如 `4D 5A ?? ??`。 |
| 4 | 保存出错，请重试 | 无法保存到 `/Volumes/USB/report.bin`：磁盘只剩 120 MB，本次写入需要 3.4 GB。请释放空间，或另存到其它磁盘。 |
| 5 | 模板执行失败 | 第 412 行 `name_len` 读到 0xFFFF 字节，超出本段剩余 12 字节。模板可能把长度字段当成了本段字段。其余 4,201 个字段已保留。 |
| 6 | 签名错误！ | 无法安装 `tpl.zip 1.4.0`：签名校验失败。摘要与索引登记不一致，包可能被篡改或传输损坏。未改动任何已安装内容，可点「重新下载」。 |
| 7 | 还原失败 | 无法自动恢复 1 个文档：journal 第 1841 条记录校验失败，前 1840 条可用。是否只恢复前 1840 条？（journal 不会被删除。） |
| 8 | 插件崩溃 | 插件 `hexdecoder` 在本次会话被禁用：连续 3 次调用超时（每次 5s）。其它插件与文件不受影响，可在 设置 > 插件 重新启用。 |
| 9 | diff 失败，内存不足 | 比对已降级为块级精度（1 块 = 64 字节）：内存峰值超过 800 MB。差异列表仍完整，但同块内的改动会合并显示。关闭其它文档可恢复字节级。 |
| 10 | 版本太新，无法打开 | 无法打开 `project.geoproj`：文件由 v4 写入，本版本最高支持 v3。升级 Geode 到 v4 才可编辑。现在可以只读查看文件原文。 |

## 5 性能预算与基准

### 5.1 交互原则

1. 一切可键盘完成：每个动作都有 `CommandId`；列表响应 `↑↓ Home End PgUp PgDn Enter Esc`；`Tab` 顺序 = 视觉顺序；连分隔条都有 `view.grow_left` 之类命令。
2. 破坏性操作二次确认：判据是「不可撤销 ∨ 覆盖不可见数据 ∨ 改变信任」，可撤销的编辑**不**确认（否则用户被训练成无脑确认）；确认按钮写动词（「覆盖保存」）。
3. 长任务永不阻塞输入且可取消：>300ms 一律进 `Job`，取消 p99 ≤100ms；取消后搜索保留部分结果并标 `complete=false`，diff 则丢弃半份（`09 §6`）。进度分级：<300ms 不显示，300ms~2s 骨架，>2s 进度条 + 取消，30s 无事件报「仍在处理」。
5. 结果分批上屏，错误可聚合但绝不静默：首批 1,000 条首帧可跳转，其余 4,096 条/帧（`08 §3.5`）；同码同类合并成计数行，但至少一条正文常驻；`log::warn` 不能代替界面（例外仅陈旧结果丢弃与缓存重建，`00 §6`）。

### 5.2 感受预算

| 场景 | 预算 | 判据 |
| --- | --- | --- |
| 打开大文件首屏 | ≤300ms 出骨架 | 骨架里能看见文件名与偏移列 |
| 搜索结果首批 | 首帧 1,000 条 | 输入后立刻能跳第一个命中 |

## 6 失败模式与降级

### 6.1 交互层失败模式

| 失败 | 用户看到 | 模态 | 可恢复 |
| --- | --- | --- | --- |
| 文案查表缺失（新码未登记） | `errors.missing.<code>` + 通用三段式兜底，计入 `CopyTable.coverage()` | 否 | 补登记即正 |
| Job 30s 无进度事件 | `仍在处理…（已 30s）` + 取消 | 否 | 是 |
| 错误出现时正在编辑 | 编辑不被打断，横幅等输入空闲再上屏（≤500ms） | 否 | 是 |

### 6.2 可访问性与降级

- 自绘网格走**可访问镜像**（`16 §4.8`）：单行文本 `偏移 0x1A3C：4D 5A 90 00，ASCII MZ..`；区域描述 `区域：hex 视图，第 4127 行，共 60 行可见，游标在第 3 字节，选区 256 字节`。
- 播报粒度：游标只在「行变化」或「停止输入 300ms」后播报；选区只播报 `选区 N 字节，起 0x…，止 0x…`；无变化不播报。结构树节点播报 `字段 name，偏移 0x1A3C，长度 4，值 3，置信 0.82`。
- 最小点击目标 24dp、分隔条命中区 6dp；对比度正文 4.5:1 / 控件 3:1 / 高对比 7:1（`16 §9`）。
- 色盲不依赖色相：Error/Warning/Info 带 `✕ ! i` 前缀；AI 置信带 `✓ ≈ ?` 徽标 + 条形长度；diff 用底色 + 左缘 3px 竖条 + 行内 `+`/`-`；补丁行用底色 + 行首标记。
- 纯键盘全流程（§9.2 每旅程都有键盘脚本，可用性测试必含一轮「不碰鼠标」）；高 DPI 下文案不依赖像素截断，省略号必配 tooltip，伪本地化 +30% 零截断。

## 7 与其它子系统的契约

| 子系统 | 本文依赖它 | 本文要求它保证 |
| --- | --- | --- |

### 8.1 i18n 文案约束

- 长度预算：中文 ×1.3 为英文上限；按钮 ≤12 全角 / ≤18 半角，横幅首句 ≤60 字，模态正文 ≤240 字；伪本地化（+30%）零截断是门禁项。
- 禁止拼句：不得 `t!("a") + name + t!("b")`；参数用命名占位符（`{offset}`、`{count}`），由 `t_fmt!` 一次成型。
- 复数与性数格：用 `...one` / `...other`（`16 §4.6`），不得手写「1 处差异」分支；语言需要更多形式时按 CLDR 类别补 key，不改调用点。
- 快捷键与菜单文字从命令注册表取：文案写 `{key:file.save}`，由 `Command.default_keys` 渲染，禁止硬编码 `Ctrl+G`。
- 截图与文案不耦合：文档与测试基线不写「如图第 3 个按钮」；线框只作结构示意，改文案不必重画线框。中英混排两侧留半角空格，错误码/偏移/命令名用等宽标记。

## 10 开放问题

1. **AI 建议面板默认展开还是折叠**：展开利于发现（`ui.ai_panel.expanded=true`），但右栏已占 320dp；候选方案是按窗口宽度自适应并记忆首次选择。
2. **首次运行是否自动装模板包**：自动装降摩擦，但与「不擅自改用户环境」冲突；倾向「预勾选 + 列出包名与大小」。
3. **错误是否合并成「通知中心」**：现在是横幅 + 折叠计数；通知中心能承载历史与复制诊断，但会推迟「可见」，需先定「至少一条正文常驻」边界。
4. **专家模式与术语统一**：`ui.copy.expert_mode` 预留了「隐藏为什么」，但「为什么」正是新手最需要的部分，需用数据决定；术语定为「游标」，05/16 正文仍写「光标」，下次修订须对齐，并建议 16 §3.1 加「区域级画面见 25 §4.2」避免两处漂移。
