# 顶部固定：查询式 + 命中数 + 版本 + 耗时 + 导出；版本号是列表可信度的唯一凭据。

# 列表不因过期清空或禁用：偏移仍有效，用户可能只想看一眼再决定是否重搜（08 §4.6）。

# 固定区：左上图名与校验结论一行；错误钉在具体节点端口上（红框 + 数字徽章）。

| 00001A30  4D 5A 90 00 03 ...     |  =  | 00001A30  4D 5A 90 00 03 ...              |

# 中缝 3 列只在「对齐坐标系」上取值，两侧永不各自滚动后修正（会有可见抖动，09 §4.7）。

# 精度标记（字节级 / 块级）常驻在计数右侧：降级绝不允许静默。
